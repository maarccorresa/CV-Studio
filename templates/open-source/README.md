# Catàleg de plantilles externes

Aquest directori conté plantilles HTML/CSS de tercers per consultar, adaptar i provar de manera independent. **No s'han integrat encara a l'editor visual de CV Studio**: són fitxers de referència.

Totes les plantilles d'aquesta importació provenen de [Awesome HTML Resume Templates](https://github.com/awesome-resume-templates/html-resume-templates) i estan publicades sota llicència **MIT**. Es conserva el codi original i s'inclou una còpia de la llicència a `awesome-html-resume-templates-LICENSE`.

| Plantilla | Categoria | Format | Descripció | Llicència | Font |
|---|---|---|---|---|---|
| Minimalist | Minimalista / Genèrica | HTML + CSS | Una columna, neta i compacta per a perfils generalistes. | MIT | [Original](https://github.com/awesome-resume-templates/html-resume-templates/tree/main/templates/01-minimalist) |
| Creative Portfolio | Creativa | HTML + CSS | Disseny visual per a disseny, creativitat i portafolis. | MIT | [Original](https://github.com/awesome-resume-templates/html-resume-templates/tree/main/templates/03-creative-portfolio) |
| ATS Friendly | Compatible amb ATS | HTML + CSS | Una columna i estructura senzilla, sense gràfics complexos. | MIT | [Original](https://github.com/awesome-resume-templates/html-resume-templates/tree/main/templates/04-ats-friendly) |
| Developer / Tech | Tecnològica / IT | HTML + CSS | Estètica tècnica i apartats per a projectes i eines. | MIT | [Original](https://github.com/awesome-resume-templates/html-resume-templates/tree/main/templates/05-developer-tech) |
| Academic CV | Acadèmica | HTML + CSS | Format ampli per a recerca, publicacions i docència. | MIT | [Original](https://github.com/awesome-resume-templates/html-resume-templates/tree/main/templates/11-academic-cv) |
| Executive | Executiva | HTML + CSS | Disseny sobri per a perfils amb experiència i responsabilitat. | MIT | [Original](https://github.com/awesome-resume-templates/html-resume-templates/tree/main/templates/13-executive) |

## Notes d'ús

- Les plantilles conserven dades d'exemple (Jane Doe i enllaços ficticis); substitueix-les abans d'utilitzar-les.
- La categoria descriu l'enfocament visual, no garanteix compatibilitat amb tots els ATS.
- S'han importat els fitxers HTML i CSS; les miniatures no s'han inclòs en aquesta primera selecció.
- Consulta també el README i la llicència de la font original abans de redistribuir modificacions.
