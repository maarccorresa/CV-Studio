# CV Studio

Crea currículums professionals directament des del navegador.

## Funcionalitats

- Editor amb previsualització A4 en directe.
- Dades personals, perfil, experiència, formació, habilitats, idiomes, projectes i certificacions.
- Tres plantilles: Modern, Clàssic i Minimalista.
- Color principal personalitzable i fotografia opcional.
- Desa automàticament al navegador amb `localStorage`.
- Importa i exporta les dades en JSON.
- Exporta el currículum a PDF mitjançant la impressió del navegador.

## Ús

Obre [CV Studio](https://maarccorresa.github.io/CV-Studio/) o executa'l localment obrint `index.html`.

Per generar un PDF, prem **Descarregar PDF** i selecciona **Desa com a PDF** al diàleg d'impressió.

## Privacitat

Les dades del currículum es processen al navegador i es guarden localment al dispositiu. No s'envien a cap servidor. Si esborres les dades del navegador, fes abans una exportació JSON per conservar una còpia.

## Tecnologies

HTML, CSS i JavaScript vanilla. Sense backend, dependències ni API externa.

## Publicació a GitHub Pages

Al repositori, ves a **Settings → Pages** i selecciona **Deploy from a branch**, branca `main` i carpeta `/ (root)`.
